# 🕹️ Projeto 3: Loja de Games

Terceiro projeto do curso da **EBAC**, desenvolvido por DiegoNT1.

Este projeto simula uma **loja virtual de jogos**, com destaque para organização de produtos, exibição visual e estrutura de uma página de e-commerce simples utilizando **HTML**, **CSS** e **Bootstrap**.

🔗 **Visualize online:**  
👉 (https://projeto-3-loja-games.vercel.app)

---

## 🔍 Visão Geral

A loja apresenta uma vitrine de jogos organizada por categorias, com destaque para:

- 🎮 Catálogo de jogos – exibição de jogos de diferentes categorias, como FPS, RPG e esportes
- 💵 Preços e promoções – apresentação dos valores e ofertas dos produtos 
- 🖼️ Imagens dos jogos – imagens ilustrativas para cada produto 
- 🎠 Carrossel de destaques – apresentação visual de jogos e promoções
- 📩 Formulário de contato – espaço para envio de mensagens

O projeto tem como objetivo praticar a criação de uma interface de e-commerce, com organização de produtos e navegação utilizando Bootstrap.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** – estrutura da página
- **CSS3** – estilização dos elementos
- **Bootstrap 5** – layout responsivo, componentes e navegação
- **Bootstrap Icons** – ícones da interface
- **Google Fonts** – fontes personalizadas
